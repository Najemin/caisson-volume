# 케이슨 체적 · 무게중심 산정 Ver.1.0 — Streamlit 판 (단일 파일)

원본 Tkinter 프로그램 `케이슨체적_v1.py` 를 웹(Streamlit)에서 그대로 쓰도록 옮긴 것이다.
계산부(§0~§4)는 원본에서 **글자 하나 바꾸지 않았고**, 화면부(§5)만 새로 썼다.
따라서 체적 · 무게중심 · 계산서 · 도면 결과는 원본과 완전히 같다.

---

## 1. 파일 구성

| 파일 | 꼭 필요한가 | 내용 |
|---|:---:|---|
| `app.py` | **필수** | 프로그램 전체 (계산부 + 화면부, 5,413행) |
| `requirements.txt` | **필수** | 파이썬 패키지 목록 |
| `packages.txt` | 사실상 필수 | 리눅스 서버용 한글 글꼴. 없으면 **도해 글자가 네모(□)로 깨질 수 있다** |
| `.streamlit/config.toml` | 선택 | 화면 색 · 업로드 용량 |
| `README.md` | 선택 | 이 문서 |

`app.py` 하나만 있어도 돌아간다. 다만 도해에 한글을 쓰려면 서버에 한글 글꼴이 있어야
한다. 프로그램이 스스로 설치된 글꼴을 뒤져 **'가'·'힣' 글리프가 실제로 들어 있는지**
확인하고 골라 쓰므로 이름이 달라도(예: `Noto Sans CJK JP`) 알아서 찾아내지만,
아예 한 벌도 없는 서버라면 글자가 네모(□)로 나온다. `packages.txt` 가 그 글꼴을
깔아 주므로 같이 올리는 편이 안전하다.

---

## 2. 내 컴퓨터에서 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 저절로 열린다 (`http://localhost:8501`).
윈도우에는 맑은 고딕이 이미 있으므로 `packages.txt` 는 필요 없다.

## 3. 깃허브에 올리기

### 3-1. 저장소 구조

폴더를 만들지 말고 **저장소 맨 위(root)에 그대로** 두는 것이 가장 안전하다.
특히 `packages.txt` 는 반드시 root 에 있어야 인식된다.

```
내-저장소/
├── app.py
├── requirements.txt
├── packages.txt
├── README.md
└── .streamlit/
    └── config.toml
```

### 3-2. 웹 브라우저로 올리는 방법 (git 몰라도 된다)

1. github.com → 우측 위 **＋** → **New repository**
2. 이름을 적고(예: `caisson-volume`) **Create repository**
3. **Add file → Upload files** 로 `app.py` · `requirements.txt` · `packages.txt` · `README.md` 를 끌어다 놓는다
4. `.streamlit/config.toml` 은 점(.)으로 시작해 탐색기에서 안 보일 수 있다. 이때는
   같은 화면에서 **Add file → Create new file** 을 누르고, 이름 칸에
   `.streamlit/config.toml` 이라고 통째로 치면 폴더가 자동으로 만들어진다.
   (내용은 파일을 열어 복사해 붙이면 된다. 없어도 프로그램은 돈다.)
5. **Commit changes**

### 3-3. git 으로 올리는 방법

```bash
cd 파일이-있는-폴더
git init
git add .
git commit -m "케이슨 체적·무게중심 산정 Streamlit 판"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```

### 3-4. 웹에 띄우기 (Streamlit Community Cloud · 무료)

1. <https://streamlit.io/cloud> 에 깃허브 계정으로 로그인
2. **New app → Use existing repo**
3. Repository = 방금 만든 저장소, Branch = `main`, **Main file path = `app.py`**
4. **Deploy** → 몇 분 뒤 `https://<이름>.streamlit.app` 주소가 나온다

저장소에 새로 commit 할 때마다 자동으로 다시 배포된다.

> 사내 자료가 들어가는 프로그램이면 저장소를 **Private** 로 두는 편이 낫다.
> Private 저장소도 배포할 수 있고, 앱 자체도 설정에서 열람 권한을 걸 수 있다.

## 4. 원본에서 손댄 곳 (세 군데뿐)

| 원본 | 여기 | 이유 |
|---|---|---|
| `import tkinter …` | 삭제 | 웹에는 창이 없다 |
| `matplotlib.use('TkAgg')` | `use('Agg')` | 화면 없는 서버용 백엔드 |
| `plt.rcParams['font.family'] = 'Malgun Gothic'` | 설치된 한글 글꼴 자동 탐색 (글리프 실측) | 리눅스 서버 대응 |

산식 · 검산 · 계산서 · 도해 · CAD 출력 코드는 한 줄도 고치지 않았다.

## 5. 화면이 원본과 다른 곳 (네 가지)

| 원본 | 여기 |
|---|---|
| 폴더 골라 저장 | 항목별 **내려받기** 버튼 + 전체 **ZIP** |
| 3D 도해 마우스 회전 | `시선각(elev/azim)` 입력칸 (기본 22 / −125 = 원본과 같은 시선) |
| `[셀 격자 갱신]` 버튼 | 격벽을 바꾸면 자동 갱신 (버튼도 남겨 두었다) |
| `[나가기]` | 웹에는 없다 → `[기본 예제로 되돌리기]` |

## 6. 단일 파일이라서 넣은 장치 하나

`app.py` 안 §4 와 §5 사이에 **「계산부 고정」** 이라는 짧은 코드가 있다.

Streamlit 은 버튼을 누를 때마다 스크립트를 **처음부터 다시 실행**한다.
그러면 `class Box`, `class CaissonEngine` 같은 문장도 다시 돌아, 이름은 같지만
**정체가 다른 새 클래스**가 만들어진다. 지난 회차에 담아 둔 엔진은 옛 클래스의
것이므로 `isinstance(p.prim, Box)` 가 거짓이 되고 — 실제로 이 장치를 빼고
시험했더니 **3D 모델에서 저판과 측벽 6개가 조용히 빠지고 체적 대조가 N.G** 로
떨어졌다. 계산서에는 아무 표시도 안 나므로 알아채기 어렵다.

그래서 맨 처음 회차의 계산부를 통째로 붙잡아 두고 다음 회차부터 그것을 쓴다.

> 파일을 `app.py` / `caisson_core.py` 둘로 나누면 파이썬의 `import` 가 이 일을
> 대신해 주므로 이 장치가 필요 없다. **한 파일로 합친 대가**로 붙인 것이니
> §4 와 §5 사이의 그 코드는 지우지 말 것.

## 7. 계산서 표가 어긋나 보일 때

계산서 표는 「한글 2칸 / 영문 1칸」 고정폭을 전제로 그린다. 그런데 `· × ³ Σ`
같은 **애매폭 문자**를 몇 칸으로 그리는지는 글꼴마다 다르다. 구분선이 어긋나면

* `7. 결과` 탭 → **[애매폭 문자 폭]** 을 `2` ↔ `1` 로 바꾼다
* 바로 아래 **[표 정렬 자체 점검]** 이 폭을 넘긴 줄을 찾아 준다
